# semanticant-core

Tiny shared types for [SemanticAnt](https://github.com/ThinkersJournal/semanticant): `Span`, `LangTag`, `Reason`, `Verdict`, `Provenance`
and the data-pack `Manifest` with its validation. Standard library only; `#![forbid(unsafe_code)]`; no model; no language hard-coded.

Stable identifiers are intentionally not here (global identity belongs to OntologicAnt). Reason rule ids are listed in `RULES.md`.
